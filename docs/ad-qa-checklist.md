# 광고 연동 QA 체크리스트

## 1. 배너 광고

- 홈 화면 하단에 배너가 정상 노출되는지 확인
- 기록 화면 하단에 배너가 정상 노출되는지 확인
- 배너가 하단 네비게이션과 겹치지 않는지 확인
- 배너 로드 실패 시에도 화면 흐름이 깨지지 않는지 확인

## 2. 전면 광고

- 오늘 첫 측정 결과 진입 직전에 전면 광고가 노출되는지 확인
- 광고 종료 후 결과 화면으로 정상 이동하는지 확인
- 같은 날 재측정에서는 과도하게 반복 노출되지 않는지 확인

## 3. 리워드 광고

- `다시 측정` 클릭 시 리워드 광고가 노출되는지 확인
- 시청 완료 후 추가 측정이 정상적으로 열리는지 확인
- 중도 종료 시 보상이 지급되지 않는지 확인
- `심층 분석` 열기 시 리워드 광고가 노출되는지 확인
- 시청 완료 후 심층 분석이 해금되는지 확인

## 4. 공통 안정성

- 광고 노출 실패 시 fallback 오버레이가 정상 동작하는지 확인
- 홈, 결과, 기록, 집중 코치 화면 전환 중 오류가 없는지 확인
- 실기기에서 스크롤 중 하단 도크와 배너 위치가 흔들리지 않는지 확인

## 5. 실기기 확인

- Android 실기기 1대 이상에서 확인
- 가능하면 iOS 실기기 1대 이상에서 확인
- 느린 네트워크 환경에서도 광고 실패 시 앱이 멈추지 않는지 확인
